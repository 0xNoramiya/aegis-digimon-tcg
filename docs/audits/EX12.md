# EX12 card verification

### EX12-052 — Diarbbitmon

The [official card image](https://world.digimoncard.com/images/cardlist/card/EX12-052.png), inspected on 2026-10-14, makes the combined +3000 DP and battle effect optional. The catalog previously put “may” only before battle. The corrected catalog and `apps/api/src/cards/EX12/EX12-052.ts` allow declining the entire effect at When Digivolving, When Attacking, and Counter timings. Accepting it still applies the bonus and requires the chosen Digimon to battle if possible, as Q6836 specifies. The shared once-per-turn key and mandatory evolution immunity are preserved.

Other printed clauses remain the green/black and alternate evolution requirements, Piercing, Vortex, opponent Digimon-effect immunity, and the Option side's NSp use requirement, optional unsuspension, two opposing suspensions, and unsuspend restrictions. There is no inherited effect. Registration remains exclusively through `registerIrCard`; the effects snapshot is synchronized.

Behavioral proof lives in `apps/api/src/engine/scenarios/optional-dp-and-battle.test.ts`: declining after a public attack leaves DP at 12000 and preserves the opposing Digimon while the security attack completes; declining after a public evolution preserves the immunity and pays the evolution cost. The shared fixture also drives `apps/web/e2e/optional-dp-and-battle.spec.ts`, which verifies the visible optional prompt, final synchronized state, and drained presentation queue. The existing card suite covers accepted battles, Counter, shared usage limits, immunity, Option behavior, and legal/illegal evolution routes.

KB Q6836 and Q6843 distinguish optional activation from battle resolution; Q6837–Q6842 and Q6844 cover immunity; Q6845–Q6848 cover Counter and Piercing interactions; Q6849 covers independent Option targets. The comparable DP-plus-Battle effects on BT25-020 and EX13-045 have separately optional battle clauses and were left unchanged.

**9/10** (c + ir + b + p + g): official text, IR, API behavior, and browser proof agree. The reported original match could not be replayed: the report's private replay timed out and the matching VPS replay file was unavailable. This verifies the independently reproduced behavior, not the original match's complete history.
